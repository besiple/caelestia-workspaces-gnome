# Caelestia Slidefade Workspaces for GNOME Shell 🌌

> Authentic **Hyprland / Caelestia** style fluid `slidefade 20%` workspace transitions with static wallpaper and smooth deceleration curves for GNOME Shell (45–51+).

Brings the signature fluid Material/Cosmic workspace animation from modern Hyprland rices (Caelestia) into GNOME Shell!

---

## ✨ Features

- **Slidefade 20% Physics**: Workspaces glide over a subtle, elegant 20% offset distance instead of a harsh 100% full-screen slide.
- **Organic Crossfade**: Incoming workspaces smoothly fade in from 0 to 100% opacity, while outgoing workspaces smoothly dissolve away.
- **Static Wallpaper (No Motion Tearing)**: The desktop wallpaper remains perfectly still while only windows and apps glide past.
- **Caelestia Deceleration Curve**: Uses smooth exponential easing (`EASE_OUT_EXPO` / `decel`) for that buttery, luxurious feel.
- **Touchpad & Shortcut Support**: Fully compatible with 3/4-finger swipe gestures, mouse wheel, and keyboard shortcuts (`Super + Alt + Left/Right`).
